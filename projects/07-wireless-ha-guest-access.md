# 07 · Wireless High Availability & Guest Access

**Customer:** MAS Intimates Bangladesh (apparel manufacturing)
**Role:** Design and implementation

## Scope
- Set up **HA between Ruckus ZoneDirector 1200 controllers** and integrated the access points
- Configured SSIDs with secure authentication, plus ACLs
- Deployed a **token-based guest pass** system for visitors

## Technologies
Ruckus ZoneDirector 1200 · Ruckus APs · controller HA · WPA2 Enterprise / PSK · ACL · guest pass portal
